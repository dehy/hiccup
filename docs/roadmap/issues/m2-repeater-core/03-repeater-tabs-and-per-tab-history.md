# Repeater tabs and per-tab history

labels: type:feature, area:repeater, area:store

## Goal

Organise repeater work and keep it across sessions.

## Tasks

- [ ] Tabs stored in the project: name, target, current raw request, options
- [ ] Per-tab history of sent requests and responses with back/forward navigation
- [ ] Create a tab from a proxy history item ("send to Repeater") or from a raw file

## Acceptance criteria

- [ ] Tabs and history survive a restart

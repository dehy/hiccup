# Spike: C# binding strategy

labels: type:spike, area:ffi, platform:windows

## Goal

Choose between `uniffi-bindgen-cs` and a `cbindgen` C ABI with P/Invoke.

## Tasks

- [ ] Prototype both with async calls and event callbacks
- [ ] Evaluate maintenance, AOT/trimming compatibility and ergonomics
- [ ] Record the decision in an ADR

## Acceptance criteria

- [ ] ADR merged with a recommendation and a working prototype

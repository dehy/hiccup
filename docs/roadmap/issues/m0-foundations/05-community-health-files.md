# Community health files

labels: type:docs, area:community

## Goal

Make the project welcoming and safe to contribute to.

## Tasks

- [ ] `CONTRIBUTING.md`: dev setup per OS, workflow, Conventional Commits, DCO sign-off (`git commit -s`), the ADR process
- [ ] `CODE_OF_CONDUCT.md`: Contributor Covenant 2.1, with a contact address
- [ ] `SECURITY.md`: private vulnerability reporting via GitHub Security Advisories, supported versions, disclosure timeline
- [ ] Issue forms (bug, feature, roadmap) and a PR template with a checklist (tests, CLI parity, docs, changelog)
- [ ] `CODEOWNERS` and `.github/FUNDING.yml` (optional)
- [ ] DCO check app or workflow

## Acceptance criteria

- [ ] GitHub's community profile shows 100% once hosted
